# TX-6

A study of teenage engineering's TX-6 mixer: modelled in Rhino, rendered and animated in Blender, then played back frame by frame as you scroll.

Plain HTML, CSS and GSAP (ScrollTrigger + Lenis from a CDN). No build step.

Live: https://shiyansagar.github.io/tx6/ · Part of [Sagar Shiyan's archives](https://sagarshiyan.vercel.app/archives/).

## Run locally

```bash
python -m http.server 8080
```

Open http://localhost:8080/.
